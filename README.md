O **MoneyZe** é uma aplicação desktop desenvolvida para auxiliar no gerenciamento financeiro pessoal de forma simples, organizada e intuitiva.

O projeto está sendo desenvolvido com foco em boas práticas de arquitetura, organização de código e experiência do usuário, oferecendo uma interface moderna para o controle de receitas, despesas, categorias e histórico financeiro.

> 🚧 **Status:** Em desenvolvimento.

## 🎯 Objetivos do projeto

Este projeto tem como objetivo:

- Praticar desenvolvimento desktop com Python;
- Aplicar princípios de arquitetura em camadas;
- Utilizar o padrão Repository e camada de Services;
- Trabalhar com SQLAlchemy e SQLite;
- Desenvolver uma interface moderna utilizando PySide6;
- Construir um projeto completo para portfólio.
